Entry for the [make.fun](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) bounty **"The GPS Swears It Was a Shortcut"** — one line of at most 200 characters: the GPS, in its own voice, explaining why it sent the driver down the wrong road.

## Entry

> the map swore it was a shortcut, so i believed it. the lake was not on my screen, the wedding was not on my calendar — and technically you did arrive, just fashionably late and slightly damp.

(191 characters, one line.)

## Run

```sh
python3 main.py
```

Pure Python standard library, no dependencies. The program prints the entry
line deterministically — the same line on every run — and also writes it to
`/output/entry.txt` when that directory exists.
